# 企业私有仓 · Agent 总则（可复制为仓库根 AGENTS.md）

你正在 **企业私有代码库** 中协助开发。必须遵守：

1. **不外泄**：不要建议把私有源码、密钥、客户数据粘贴到公网服务或未授权渠道。
2. **源仓只读脱敏**：禁止为了「脱敏/去噪」改写私有仓文件；应通过 coding-scaffold 的 **动态注入**（`resolve_context.py` / Inject Sanitized Context）在内存中清理后再进 Agent 上下文。
3. **先边界后编码**：涉及读取多文件前，优先遵守仓库内的 `.haxitag/workspace-policy.yaml`（或团队等价策略）。
4. **密钥零容忍**：发现疑似密钥/证书，停止扩散，提示改用环境变量或 secret manager。
5. **最小必要上下文**：只打开与当前任务相关的文件；不要主动整仓扫描进对话。
6. **可审计改动**：提交信息与 PR 描述写清「改了什么、为什么」，避免无意义大面积格式化。

本仓库由 HaxiTAG coding-scaffold 的企业私有仓实践引导；详见团队文档。
